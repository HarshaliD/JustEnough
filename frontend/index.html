How JustEnough Works

      
Five deterministic steps between your document and the AI.

      

        

          
1

          

            
          

          
Detect

          
Presidio + custom Indian-format patterns identify 16 sensitive categories locally.

        

        
→

        

          
2

          

            
          

          
Skeleton

          
Detected values are replaced with typed placeholders [NAME], [ACCT], [CIF] before Gemini sees any text.

        

        
→

        

          
3

          

            
          

          
Plan

          
Gemini proposes KEEP / DROP / MASK_PARTIAL / GENERALIZE / PSEUDONYMIZE / AGGREGATE per category.

        

        
→

        

          
4

          

            
          

          
Policy Floor

          
Government IDs and full account numbers are deterministically clamped regardless of model output.

        

        
→

        

          
5

          

            
          

          
Transform

          
Deterministic Python code applies the approved plan locally. No LLM rewrites your document.
